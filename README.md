# 🚩 RedFlag — Fraud Detection Using SQL

A SQL-based fraud detection project focused on identifying potentially suspicious transaction patterns from **200,000 synthetic payment transactions**.

## 📌 Project Overview

RedFlag analyzes transaction data using MySQL to detect patterns that may indicate fraudulent or unusual activity.

## 🔍 Fraud Patterns Analyzed

* Transaction Velocity
* Round-Amount Clustering
* Card Testing
* Failed → Successful Transactions
* Odd-Hour Concentration
* Mule Account Behavior
* Refund Abuse
* Merchant Collusion
* ₹9,999 Threshold Transactions
* Dormant → Active Accounts
* Monthly Velocity Spikes
* Geographic Impossibility

## 🛠️ SQL Concepts Used

`GROUP BY` · `HAVING` · `JOINs` · `CASE WHEN` · `CTEs` · `Window Functions` · `LAG()` · `ROW_NUMBER()` · `TIMESTAMPDIFF()`

## 🎯 Objective

To apply SQL to a practical fraud detection use case and strengthen **SQL, data analysis, and problem-solving skills** through transaction-level analysis.

## 📂 Dataset

* **200,000 synthetic transactions**
* Transaction period: **January 2024 – June 2024**
* Payment aggregator: **PayFast (fictional)**

## 👩‍💻 Skills Demonstrated

**SQL | MySQL | Data Analysis | Fraud Detection | Analytical Thinking**
